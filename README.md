# Sales Performance Dashboard

A data analytics and business intelligence project that analyzes sales data and presents key business insights through an interactive Power BI dashboard.

# 📊 Project Overview

The project focuses on analyzing sales performance, revenue, customers, products, orders, and customer segments.

The data is processed and prepared for analysis and then visualized using Microsoft Power BI to create an interactive Sales Performance Dashboard.

# 🚀 Dashboard

The dashboard provides insights into:

- Total Revenue
- Total Orders
- Total Customers
- Average Order Value
- Repeat Purchase Rate
- Top Products by Revenue
- Quantity Sold by Country
- Revenue by Customer Segment
- Revenue Trends
- Monthly Revenue
- Country-wise Sales Performance

# 🛠️ Technologies Used

- **Python** – Data processing and preparation
- **Pandas** – Data manipulation and analysis
- **SQL** – Data querying and structured data handling
- **Microsoft Power BI** – Data visualization and dashboard development
- **DAX** – Measures and analytical calculations
- **Git & GitHub** – Version control and project hosting
